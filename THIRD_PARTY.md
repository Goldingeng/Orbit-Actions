# Third-party code and assets

Orbit Actions is a fork of [Kando](https://github.com/kando-menu/kando). The following parts come from Kando or other projects and keep their licenses.

| Path | Source | License |
|---|---|---|
| Menu logic, layout math, input handling, workflow actions | [Kando](https://github.com/kando-menu/kando) by Simon Schneegans | MIT |
| `assets/locales/*.json` | Kando translations | MIT |
| `assets/example-menu.json` | Kando example menu, modified | MIT |
| `assets/action-icons/*.svg` | Kando icon theme, partly based on [Tabler Icons](https://github.com/tabler/tabler-icons) by Paweł Kuna | MIT |
| `assets/themes/default`, `clean-circle`, `neon-lights`, `rainbow-labels` | Kando menu themes by Simon Schneegans | CC0-1.0 |

| `assets/tutorial/*.svg` | Kando tutorial pictures by Simon Schneegans | CC-BY-4.0 |
| `assets/sounds/simple-clicks/*.wav` | Sounds from Pixabay (freesound_community, 666HeroHero), as packaged in Kando's "Simple Clicks" sound theme | Pixabay Content License |
| `assets/material.ttf`, `assets/material.txt` | [Material Symbols](https://github.com/google/material-design-icons) by Google | Apache-2.0 |
| `assets/simple.ttf`, `assets/simple.txt` | [Simple Icons](https://github.com/simple-icons/simple-icons) | CC0-1.0, brand logos remain trademarks of their owners |
